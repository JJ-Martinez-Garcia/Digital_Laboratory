# Digital Laboratory

Public static edition of the Digital Laboratory by José Javier Martínez García.

The site preserves the public landing page, multilingual interface, animated orbit control, application catalogue, download links and external application links from the original ChatGPT Site publication.

## Public site

https://jj-martinez-garcia.github.io/Digital_Laboratory/

## Deployment

Every push to `main` is deployed automatically to GitHub Pages by [`.github/workflows/deploy-pages.yml`](.github/workflows/deploy-pages.yml). The project is a static export, so no package installation or build step is required.

## Scope

The linked applications remain hosted at their existing public URLs or GitHub release pages. This repository contains the Digital Laboratory portal and its public assets; it does not duplicate the application backends or private data.
